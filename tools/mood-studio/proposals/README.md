## إعادة التوليد

```bash
cd tools/mood-studio/proposals
node build-gallery.mjs      # يكتب out/01.png ... out/15.png
```

يحتاج `perfumes.json` و`pool.json` و`photo1.jpg`/`photo2.jpg` بالمجلد الأب،
و`fonts/` فيه نسخة محلية من Google Fonts (أو احذف اعتراض الطلبات ودع الخطوط
تُحمّل من الشبكة).

`pool.json` هو الكتالوج مصفّى على العطور التي لها صورة في `newprod/`، مع
حقل `_img` لكل واحد. `photo1.jpg` و`photo2.jpg` قصّتان من ستوري حقيقي —
لقطة اليد — تُستخدم في التصاميم ١٠–٠١ و١٣ لأن صور الكتالوج كلها استوديو
بخلفية بيضاء (أفتحها ٠.٤٨) ولا تمثّل التصوير الفعلي.

الملفات: `tpl-core.js` أدوات مشتركة، `tpl-a.js` تصاميم ٠١–٠٥،
`tpl-b.js` تصاميم ٠٦–١٠، `tpl-c.js` أنواع المحتوى ١١–١٥.
